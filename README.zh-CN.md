## 准入测试

每条公开记录必须且只能属于以下两种角色之一：

1. **生成方法**：论文的核心贡献直接产出可运行游戏、可执行代码/工程、可执行规则/机制、可玩关卡/地图/任务/谱面，或玩家可控制的生成式游戏世界。
2. **生成 Benchmark**：论文正式定义上述生成任务之一，并给出实证评测协议。

被提出或评测的研究对象必须是生成工件，而不是智能体得分、策略回报或游玩能力。

## 不收录

- 玩游戏的智能体、NPC/玩家策略和 gameplay benchmark。
- 纯数据集/语料库论文、综述、分类论文和立场论文。
- 通用基础设施、没有实质自动生成器的创作工具，以及纯指标研究。
- 没有直接生成器的独立验证、修复、QA 或参数调优工作。
- 单独生成图像、纹理、3D 资产、音乐、对话、故事、卡牌或其他孤立组件的工作。
- 没有逐步玩家控制闭环的提示词游戏视频，以及以规划或策略学习为核心的 world model。

如果论文混合使用试玩、搜索、RL 或自博弈，只有在这些技术直接生成或评测生成工件时才收录。完整判定规则见 [SCOPE.md](SCOPE.md)。

## 工件标签

| 标签 | 含义 |
| --- | --- |
| **Open** | 已核验到官方核心实现和有意义的复现工件 |
| **Partial** | 存在官方发布，但缺少关键组件 |
| **Closed** | 未核验到可运行的官方核心发布 |

这些标签只描述工件可用性，不代表论文质量。
