## 访问与比较注意事项

1. **不要跨协议直接比较分数。** ALE 的 sticky actions、Procgen 的 train/test levels、SMACv2 的 held-out scenarios，以及 Minecraft 版本或交互预算都会显著改变结果。
2. **不要用 arithmetic mean 掩盖任务差异。** 适当报告逐任务结果、median、IQM/置信区间和失败率；Crafter 应使用官方几何平均分。
3. **商业游戏须单列访问说明。** VideoGameBench、StarCraft II、Honor of Kings 和 Minecraft 可能要求合法持有游戏或 ROM、下载客户端、接受 EULA 或使用特定版本。VideoGameBench 代码采用 MIT 许可，但 ROM 和商业游戏不随该许可分发。
4. **代码与数据适用不同条款。** GameBench 代码采用 MIT 许可，比赛数据采用 CC-BY；MACHIAVELLI 数据需另行下载。有 GitHub 仓库并不代表游戏、客户端、数据、账号或全部评测资产均开放。
5. **公开代码不自动等于公开 benchmark。** AlphaStar、OpenAI Five、SIMA 和 XLand 在缺少完整训练与评测资产时仍只能列为 agent paper。
6. **记录旧仓库状态并固定版本。** Malmo 和原 Google Research Football 仓库已归档，Procgen 处于 maintenance mode，NLE/MiniHack 的维护已从旧 Facebook 仓库迁出；当前 NLE 使用 NetHack 3.6.7。应链接当前维护位置，并固定 commit/version 以保证复现。
