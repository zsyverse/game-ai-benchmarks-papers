## 关键注意事项

1. **可玩 demo 不等于 benchmark。** 没有固定任务与评分器时，Genie、GameNGen、Oasis、Hunyuan-GameCraft 等应列入论文/工具部分，而不是 benchmark leaderboard。
2. **world model 与 game-building agent 解决不同任务。** 前者在 action 条件下预测 pixels 或 latents；后者生成或修改代码、场景和资产，并需通过 engine/runtime tests。两者应分榜。
3. **model judge 分数与确定性测试应分开。** GameDevBench 与 GameEngineBench 的行为测试更可重复；GameCraft-Bench 与 V-GameGym 覆盖更丰富的视觉/体验维度，但依赖 judge model 和版本。
4. **使用时重新检查数据与许可。** OGameData 等 YouTube-ID 数据集会发生链接失效；Unreal、EOS、Atari 等资源还可能需要引擎、SDK、ROM 或素材许可。
5. **截止检索日不要把 GameXpert-Bench 或 JamBench 标为“可下载”。** 前者仓库明确表示发布工件仍待补齐；后者没有可核验的官方 artifact URL。
