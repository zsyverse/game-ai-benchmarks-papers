Source cutoff: **2026-08-29**. `[B]` denotes a benchmark or environment with explicit tasks or an evaluation protocol; `[P]` denotes a research platform without one fixed task set or overall score; `[P/B]` can serve both roles. Scores are comparable only when versions, budgets, seeds, splits, opponents, and aggregation rules match.

## Access and comparison caveats

1. **Do not compare scores across protocols.** ALE sticky actions, Procgen train/test levels, SMACv2 held-out scenarios, and Minecraft versions or interaction budgets materially change results.
2. **Do not hide task variation behind an arithmetic mean.** Include per-task results, median, IQM/confidence intervals, and failure rate where appropriate; use Crafter's official geometric-mean score.
3. **Commercial games require separate access notes.** VideoGameBench, StarCraft II, Honor of Kings, and Minecraft may require a legally owned game or ROM, a client download, acceptance of an EULA, or a particular version. VideoGameBench's code is MIT-licensed, but its ROMs and commercial games are not distributed under that license.
4. **Code and data have different terms.** GameBench's code is MIT-licensed and its match data is CC-BY; MACHIAVELLI data is a separate download. A GitHub repository does not imply that the game, client, data, accounts, or every evaluation asset is open.
5. **Public code is not automatically a public benchmark.** AlphaStar, OpenAI Five, SIMA, and XLand remain agent papers when complete training and evaluation assets are unavailable.
6. **Record legacy-repository status and pin versions.** Malmo and the original Google Research Football repository are archived, Procgen is in maintenance mode, and NLE/MiniHack maintenance moved away from the old Facebook repositories; current NLE targets NetHack 3.6.7. Link the maintained location and pin a commit/version for reproducibility.
