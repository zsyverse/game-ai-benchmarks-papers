# End-to-End Game Generation: Benchmarks and Papers

[Home](../../README.md) · [中文](../zh-CN/end-to-end.md) · [Automated design & PCG](pcg.md) · [Interactive worlds](interactive-worlds.md) · [Scope](../../SCOPE.md)

> Research cutoff: **2026-08-29 (Asia/Shanghai)**. This index covers systems that turn prompts, specifications, or rules into executable games, game projects, game code, or verification/editing artifacts for generated games. It **excludes game-playing papers** whose main objective is learning policies, raising scores, or winning existing games.

Level-only, asset-only, and action-conditioned video world models are outside the core scope. Gameplay, self-play, or GUI agents appear here only when they test or repair a generated game. **Open** means the core artifacts are public; **Partial** means only some components, demos, or evaluation materials are public; **Closed** means no reproducible official release was verified at the cutoff.
