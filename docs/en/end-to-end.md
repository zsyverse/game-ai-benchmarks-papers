# End-to-End Game Generation: Benchmarks and Papers

[Home](../../README.md) · [中文](../zh-CN/end-to-end.md) · [Automated design & PCG](pcg.md) · [Interactive worlds](interactive-worlds.md) · [Scope](../../SCOPE.md)

> Research cutoff: **2026-08-31 (Asia/Shanghai)**. This index contains **50 generation-only entries**: systems that turn prompts, specifications, examples, or rules into executable games, game projects, game code, mechanics/rules, or verification/editing artifacts for generated games. It **excludes game-playing papers** whose main objective is learning policies, raising scores, or winning existing games.

Level-only, asset-only, and action-conditioned video world models are outside the core scope. Gameplay, self-play, or GUI agents appear here only when they evaluate, repair, or balance a generated design. **Open** means the core artifacts are public; **Partial** means only some components, demos, data, or evaluation materials are public; **Closed** means no reproducible official release was verified at the cutoff.
