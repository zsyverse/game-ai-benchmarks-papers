# 游戏生成调研可靠性复核 — 2026-09-05

## 结论与责任边界

上一轮增补存在事实压缩失真、工件误判和不同论文合并错误。新增数量与 Markdown 校验都不能证明研究结论可靠。本轮对上一轮 **41 个新增记录**按端到端 3、历史规则 5、PCG 内容 20、交互世界 13 四组复核，并检查由此暴露的部分既有合并记录；不是重新审计全部历史文献，也不是实验复现。

没有为了显示“严格”而整批删除工作。保留或暂缓均依据 [SCOPE](../SCOPE.md)：直接生成且评测可执行游戏、规则、可玩内容或逐步响应输入的世界。导航交互可以符合世界类范围；模拟器可执行规则也可以符合规则类范围，但不能因此宣传成完整成品游戏。

## 这轮仍不能保证什么

1. **不是系统综述穷举。** 尚未逐年遍历所有会议、学位论文库与非 arXiv 历史资料；不会把“未搜到”写成“不存在”。
2. **不是全库事实重新认证。** 本轮重点是 41 个新增记录及明确暴露的合并/分类错误。其他历史会议—期刊扩展关系、抽象地图的可玩性边界仍需另做一致性审计。
3. **不是独立复现。** 没有运行第三方生成器、训练模型或重复玩家实验。Open/Partial 只说明核验到哪些官方工件，不保证结果可重现或开箱即用。
4. **访问失败不是缺失证据。** GitHub API 限流时改查官方原始 README、目录或模型清单；仅有访问错误时保留访问限制，不能推断仓库为空。
5. **格式校验只保格式。** 双语标题、链接、连续编号、数量和测试校验能发现索引结构问题，不能验证论文的方法正确性或实验可信度。

研究导读同步收紧了方法族的能力措辞：以“搜索/尝试满足目标”代替保证可玩或保证可控；取消容易误解为单一版本继承的谱系箭头。结论须与原文的任务、样本分母、负面结果和工件边界一起阅读。
